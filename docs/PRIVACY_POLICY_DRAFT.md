## 1. Summary

Restaurant Empire is an offline game. The current build does not create user accounts, display advertisements, use analytics, make network requests, or intentionally collect, transmit, sell, or share personal data.

## 2. Data stored locally

The application stores gameplay information only on the user's device, including:

- game progress, currencies, upgrades, employees and unlocked content;
- inventory, crops, garden plots, recipes and temporary boosts;
- preferences such as audio settings and tutorial progress;
- save version and local timestamps used to calculate capped offline progress.

This information is used only to run the game, restore progress and calculate offline rewards. It is not transmitted to the publisher in the current build.

## 3. Network access, analytics, advertising and purchases

The current build contains no online account system, cloud save, advertising, analytics, social feature, telemetry, real-money purchase or third-party tracking SDK. Android network permissions are disabled in the release preset.

If any of these features are introduced, this policy and the Google Play Data safety declaration must be reviewed before that updated build is distributed.

## 4. Data sharing and sale

The current build does not share or sell personal data because it does not intentionally collect or transmit personal data.

## 5. Retention and deletion

Gameplay data remains in the application's local storage until the user clears the app data, resets the save in an authorized debug build, or uninstalls the application. Because the current build has no server or account, the publisher does not hold a remote copy and cannot remotely restore or delete local progress.

## 6. Children

The application is not yet enrolled in Google Play's Families program and no final target-age decision has been made. The publisher must complete the Target audience and content questionnaire accurately before release. The game does not currently collect personal data or show ads.

## 7. Security

Local saves use the operating system's application storage. No method of storage is guaranteed to be perfectly secure. Users should protect access to their device. The current save format is intended for gameplay persistence and is not a secure vault for sensitive information; the game does not ask users to enter sensitive information.

## 8. Changes to this policy

The policy may be updated when the application's features or legal requirements change. The effective date at the top will be updated. Material changes should be reflected both at the public policy URL and in the in-app privacy screen.
